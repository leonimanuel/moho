# Gather Requirements

## Workflow Steps

### [x] Step: Requirements
<!-- chat-id: 8007b969-4c38-44e8-8653-118f9ea57410 -->

Create a Product Requirements Document (PRD) based on the feature description.

Review existing codebase to understand current architecture and patterns
Analyze the feature definition and identify unclear aspects
Ask the user for clarifications on aspects that significantly impact scope or user experience
Make reasonable decisions for minor details based on context and conventions
If user can't clarify, make a decision, state the assumption, and continue
Note the branch for this work at the top of the PRD like this: BRANCH: <branch_name>

Save the PRD to requirements/<branch_name>.md at the repo root.
